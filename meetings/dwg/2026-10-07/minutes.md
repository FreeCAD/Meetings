## Topics

### Automated Meeting Bot (Crow)

sliptonic demonstrated a bot named Crow that automatically joins scheduled meetings via public links, records separate audio streams for each participant to identify speakers, generates transcripts using an LLM, and submits meeting minutes as a pull request to a repository. The bot checks the calendar every 15 minutes and can be configured via a blacklist to skip specific meetings.

### Centralized Meetings Repository

sliptonic proposed creating a new 'meetings' repository within the FreeCAD organization to centralize agendas and minutes for all meeting types (FPA, developer, CAM, etc.), replacing the current scattered approach. This repository would also host the source code for the Crow bot, allowing it to automatically locate agendas and submit minutes.

### Library System for Assets

The group discussed the need for a standardized library system to handle large assets (such as CAM workholding, BIM components, or materials) without requiring users to download entire collections. The discussion highlighted that while the Addon Manager is suitable for registering and tracking usage (telemetry), the actual distribution mechanism should fetch assets on demand. Frank is developing a pull request to implement this pattern, which could serve multiple workbenches.

### Addon Manager Improvements

Joe (Obelisk) and sliptonic discussed limitations in the current Addon Manager, specifically the lack of automatic update notifications at startup. They agreed that users need better visibility regarding available updates, suggesting potential UI indicators like a toolbar button that changes color when updates are pending.

### NX UI Features and FreeCAD Parallels

creymore shared their screen to demonstrate features in Siemens NX, including assembly navigation, sketch attachment workflows, contextual toolbars, and the use of the middle mouse button for dialog progression. The group discussed how these patterns could inspire FreeCAD improvements, particularly regarding task panel organization and selection filters.

### NX-Style Addon Demonstration

Joe (Obelisk) demonstrated an addon they are developing to bring NX-style interactions to FreeCAD. Features included making bodies active containers on double-click, a rollback bar limited to the active body, dependency arrows in the tree view, direct editing of feature parameters via input fields and a 'detail strip', toast notifications for undo operations, and reordering features in the tree with dependency validation.

## Decisions

- The participants agreed to proceed with creating a centralized meetings repository in the FreeCAD organization to host agendas, minutes, and the Crow bot source code.
